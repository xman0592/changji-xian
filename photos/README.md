# 门店照片放这里

邀请函（H5 页面和微信长图）会读取本目录下的照片，放进同名文件即生效，不用改代码。

## 文件名约定

| 文件 | 用在哪 | 建议尺寸 |
|---|---|---|
| `env-1.jpg` | 环境展示 · 大厅 | 800×600 以上 |
| `env-2.jpg` | 环境展示 · VIP 包厢 | 800×600 以上 |
| `env-3.jpg` | 环境展示 · 茶歇卡座 | 800×600 以上 |
| `manager.jpg` | 专属服务经理头像 | 正方形，400×400 以上 |
| `dish-菜名.jpg` | 菜品展示，如 `dish-焖河豚.jpg` | 800×600 以上 |

菜品文件名必须和系统里的菜名完全一致（含标点）。当前展示的六道经典菜：
生腌小白虾、醉排骨、焖河豚、清蒸海区大黄鱼、半酒炖蛏、穆阳花饺。

## 规则

- 只支持 `.jpg`；没有对应文件时自动显示深绿渐变占位块，不影响使用。
- 单张建议压到 300KB 以内（微信朋友圈加载快）。
- 改完照片不用改代码，重新发布（或刷新线上部署）就生效。
